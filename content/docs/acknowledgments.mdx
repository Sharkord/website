Sharkord exists because of these projects:

- [Bun](https://bun.sh): runtime, bundler, and test runner
- [mediasoup](https://mediasoup.org): WebRTC routing for voice, webcam, and screen sharing
- [tRPC](https://trpc.io): typed client/server communication
- [Drizzle ORM](https://orm.drizzle.team): database layer, on SQLite
- [React](https://react.dev): the web client
- [Radix UI](https://www.radix-ui.com) and [shadcn/ui](https://ui.shadcn.com): UI primitives
- [Tailwind CSS](https://tailwindcss.com): styling

Thanks also to everyone who has opened an issue, sent a pull request, or published a plugin.

If you want to support the project, it has a [Ko-fi](https://ko-fi.com/B0B71U3476).
