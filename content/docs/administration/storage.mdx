Uploads are stored on disk in `public/` inside the [data directory](/docs/data-dir). No S3. Settings are in the Storage tab and need **Manage storage**.

## Signed URLs

**Off by default. Turn it on for a private server.**

- **Off:** anyone with a file URL can download it, no login.
- **On:** URLs carry an expiring token (30 min to 7 days, default 1 hour). Clients refresh them on their own. The server logo stays public.

## Quotas

| Setting | Default |
| --- | --- |
| Server quota | 100 GB |
| Per-user quota | unlimited (`0`) |
| Max file size | 2 GB |
| Max files per message | 10 |

When the server quota is full, it either rejects new uploads (default) or **deletes the oldest files**. The second one is permanent.

Per-user quotas can be raised per [role](./roles-permissions#storage-quotas-per-role).

<Alert type="warning" title="Nginx">
  Nginx caps request bodies at 1 MB by default, which breaks uploads. Set
  `client_max_body_size 0`. See [Nginx](/docs/https/nginx).
</Alert>

## Image Optimization

Off by default. When on, JPEG, PNG, WebP, HEIC and HEIF uploads are converted to WebP (quality 1 to 100, default 80) and the original is replaced. If WebP comes out bigger, the original is kept. GIFs and videos are untouched.

## Deleting

- Deleting a message deletes its files.
- Deleting a user normally keeps their messages and files under a placeholder account. Wipe mode deletes them.
- Files a plugin attached to messages stay after the plugin is removed, listed as **Uninstalled** in the Storage tab, until those messages are deleted.
