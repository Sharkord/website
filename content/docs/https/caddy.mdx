---
title: Caddy
description: Caddy as the reverse proxy, with automatic certificates.

---

Install Caddy (`apt install caddy` on Debian and Ubuntu, or see [caddyserver.com](https://caddyserver.com/docs/install)). Then `/etc/caddy/Caddyfile`:

```
sharkord.example.com {
    reverse_proxy 127.0.0.1:4991
    encode gzip
}
```

```bash
sudo systemctl reload caddy
```

Caddy handles certificates, WebSockets and `X-Forwarded-For` on its own. Nothing to configure in Sharkord.

## Firewall

```bash
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 40000/tcp
sudo ufw allow 40000/udp
```

Keep `4991` closed. Caddy reaches it on localhost.
