Sharkord is a self-hosted voice, video and text chat server for small and medium private groups. One binary or one Docker image holds the server and the web client.

<Alert type="warning" title="Alpha software">
  Expect bugs and breaking changes. Back up before every update.
</Alert>

- New here? Start with the [Quick Start](/docs/introduction/quick-start).
- Want to try it first? [demo.sharkord.com](https://demo.sharkord.com). Voice capacity there is limited.
- Building a plugin? Go to [Plugins](/docs/plugins/overview).
