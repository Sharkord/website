description: Run Sharkord as a systemd service with Quadlets.

Rootful Podman with Quadlets. `/etc/containers/systemd/sharkord.container`:

```ini
[Unit]
Description=Sharkord

[Container]
Image=docker.io/sharkord/sharkord:latest
ContainerName=sharkord
Volume=sharkord:/home/bun/.config/sharkord
PublishPort=127.0.0.1:4991:4991/tcp
PublishPort=40000:40000/tcp
PublishPort=40000:40000/udp
# Environment=SHARKORD_WEBRTC_ANNOUNCED_ADDRESS=your-domain.com

[Service]
Restart=always
TimeoutStartSec=60

[Install]
WantedBy=default.target
```

```bash
podman pull docker.io/sharkord/sharkord:latest
systemctl daemon-reload
systemctl start sharkord
podman logs sharkord   # to read the access token on first run
```

Do not run `systemctl enable`. Quadlets are generated units and the `[Install]` section already handles boot. Remove it if you do not want autostart.

Port `4991` is bound to loopback, so point a reverse proxy at `127.0.0.1:4991`. Port `40000` must be open to the internet.

Data lives in the `sharkord` volume: `/var/lib/containers/storage/volumes/sharkord/_data/`.

## Updating

```bash
systemctl stop sharkord
podman pull docker.io/sharkord/sharkord:latest
systemctl start sharkord
podman image prune -f
```

## Caddy

No reverse proxy yet? `/etc/containers/systemd/caddy.container`:

```ini
[Unit]
Description=Caddy

[Container]
Image=docker.io/library/caddy:alpine
ContainerName=caddy
Volume=caddy_conf:/etc/caddy
Volume=caddy_data:/data
Network=host

[Service]
Restart=always

[Install]
WantedBy=default.target
```

Put this in `/var/lib/containers/storage/volumes/caddy_conf/_data/Caddyfile`:

```
sharkord.example.com {
    reverse_proxy 127.0.0.1:4991
}
```

```bash
systemctl daemon-reload
systemctl start caddy
```
