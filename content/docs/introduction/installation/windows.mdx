<Alert type="warning" title="Windows support is rough">
  Sharkord is developed and tested mainly on Linux. The Windows build still has
  problems, especially with voice. If you hit them, run Sharkord under
  [Docker](/docs/introduction/installation/docker) or WSL2 instead.
</Alert>

### 1. Install the Runtime

Sharkord needs the Microsoft Visual C++ 2015-2022 Redistributable (x64). Without it the server fails to start.

[Download it here](https://aka.ms/vs/17/release/vc_redist.x64.exe)

### 2. Download and Run

1. Download `sharkord-windows-x64.exe` from [GitHub Releases](https://github.com/Sharkord/sharkord/releases/latest).
2. Open PowerShell or Command Prompt in the folder you downloaded it to.
3. Run it:

```powershell
.\sharkord-windows-x64.exe
```

Keep the window open. Closing it stops the server.

Then open `http://localhost:4991` in your browser.

Sharkord stores its data in `%APPDATA%\sharkord`. See [Data Directory](/docs/data-dir).

### Next Steps

Set up [HTTPS](/docs/https/caddy). Without it, browsers block the microphone, webcam, and screen sharing.
