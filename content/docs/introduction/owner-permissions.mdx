---
title: Owner Permissions
description: Use the access token to claim the owner role.
icon: KeyRound
---

The access token printed on first start turns an account into the server owner.

1. Log in with the account that should own the server.
2. Open the browser console (`Ctrl+Shift+I`, **Console** tab).
3. Run `useToken("your_token_here")`.

The role applies immediately. Attempts are limited to 5 per minute.

<Alert type="attention" title="The token is a master key">
  It works from any account, any number of times, and cannot be rotated or
  revoked. Store it like a root password.
</Alert>

Lost it? There is no recovery. If you still have owner access, nothing is lost. If you do not, the only way back is a fresh [data directory](/docs/data-dir).
