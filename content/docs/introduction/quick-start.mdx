1. Install it with [Docker Compose](/docs/introduction/installation/docker-compose) (recommended, includes HTTPS), [Docker](/docs/introduction/installation/docker), [Podman](/docs/introduction/installation/podman) or the [binary](/docs/introduction/installation/binary).
2. Save the **access token** printed on first start. It is shown once and cannot be recovered.
3. Open the server, create your account, and [claim ownership](/docs/introduction/owner-permissions) with the token.

Prefer video? [How To Deploy Sharkord In 1 Minute](https://www.youtube.com/watch?v=Baa7uEKUkgQ).

## What You Need

- **HTTPS.** Browsers block the microphone, webcam and screen sharing on plain HTTP, except on `localhost`. See [HTTPS](/docs/https/why). No domain? Get a [free subdomain](/docs/domains).
- **Port `40000` open on TCP and UDP.** Voice and video go there directly, never through your reverse proxy.
- **`SHARKORD_WEBRTC_ANNOUNCED_ADDRESS`** set to your public IP or domain if the server is behind NAT or Docker. See [Configuration](/docs/configuration).
