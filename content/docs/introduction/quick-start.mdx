</Alert>

Sharkord ships as a single binary that contains both the server and the web client. There is nothing else to install.

1. Download the latest release for your platform from [GitHub Releases](https://github.com/Sharkord/sharkord/releases/latest), or use the [Docker image](/docs/introduction/installation/docker).
2. Run it: [Linux](/docs/introduction/installation/linux), [Windows](/docs/introduction/installation/windows), [macOS](/docs/introduction/installation/macos).
3. Open `http://localhost:4991` in your browser and create your account.

If the server runs on another machine, replace `localhost` with its IP address or domain.

### First Launch

The first run creates the [data directory](/docs/data-dir), writes a default [`config.ini`](/docs/configuration), and prints an access token to the console:

```
🚨🚨 I M P O R T A N T 🚨🚨
────────────────────────────────────────────────────
This server has been started for the first time.
Please save this access token somewhere safe, as it will not be shown again and there is no way to recover it.
The access token below is used to gain admin privileges. Anyone with this token can take over the server.
```

Copy it somewhere safe. It is shown once, it cannot be recovered, and anyone who has it can claim ownership of your server. See [Gain Owner Permissions](/docs/introduction/owner-permissions) for how to use it.
