Plugins can register custom commands with typed arguments and custom execution logic.

### Register a Command

```ts
import { createRegisterCommand, type PluginContext } from "@sharkord/plugin-sdk";

type Commands = {
  hello: {
    args: { name: string };
    response: string;
  };
};

const onLoad = (ctx: PluginContext) => {
  const registerCommand = createRegisterCommand<Commands>(ctx);

  // by using the registerCommand helper, we get type safety for the command name, arguments and response
  registerCommand(
    "hello",
    {
      description: "Tells the executor hello with their user id.",
      args: [{ name: "name", type: "string", required: true }],
    },
    async (invoker, args) => {
      return `Hello, ${args.name}!. Your user ID is: ${invoker.userId}`;
    },
  );
};

export { onLoad };
```

Each argument supports `name`, `description`, `type`, `required`, and `sensitive`.

```ts
args: [
  {
    name: "token",
    description: "API token used to reach the external service.",
    type: "string",
    required: true,
    sensitive: true,
  },
]
```

Set `sensitive: true` for secrets. Sensitive values are masked in the interface.

See also [Actions](./actions) when you need a server operation to be triggered from plugin UI.
