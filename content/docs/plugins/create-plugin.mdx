This guide walks through the smallest plugin shape that matches the current scaffold.

### 1) Create a Plugin Directory

Initialize a new plugin:

```bash
bun create github.com/Sharkord/plugin-example
```

### 2) Link the needed packages

To do this, first clone the Sharkord repository:

```bash
git clone https://github.com/Sharkord/sharkord.git
```

Install dependencies and link the correct packages:

```bash
cd sharkord

bun install

cd ./packages/plugin-sdk
bun link

cd ../ui
bun link
```

Now exit the Sharkord repo and clone another repo: the plugin builder, which is a template for building plugins with the correct configuration and build scripts:

```bash
git clone https://github.com/Sharkord/plugin-builder.git
```

Then install dependencies and link the package:

```bash
cd plugin-builder

bun install

bun link
```

Then, in your plugin directory, link the SDK and UI:

```bash
cd plugin-example

bun link @sharkord/plugin-sdk
bun link @sharkord/ui
bun link @sharkord/plugin-builder
```

### 3) Change the manifest file

Go to `manifest.json` and edit the information to match your plugin. The `id` field is important: it should be a unique identifier using only lowercase letters, numbers, and dashes.

Example:

```json
{
  "id": "plugin-example",
  "name": "Plugin Example",
  "author": "Me",
  "description": "This a Sharkord plugin example.",
  "homepage": "https://some-page.com",
  "logo": "https://placehold.co/100x100/white/black",
  "sdkVersion": 1,
  "version": "0.0.1"
}
```

### 4) Edit the Generated Files

The scaffold already gives you everything you need to start:

- `src/server/index.ts`
- `src/client/index.ts`
- `src/contracts/actions.ts`
- `src/contracts/commands.ts`

Start by editing the generated files instead of creating new entrypoints.

```ts
import {
  createRegisterAction,
  createRegisterCommand,
  type PluginContext,
} from "@sharkord/plugin-sdk";
import type { Actions } from "../contracts/actions";
import type { Commands } from "../contracts/commands";

const onLoad = async (ctx: PluginContext) => {
  const registerAction = createRegisterAction<Actions>(ctx);
  const registerCommand = createRegisterCommand<Commands>(ctx);

  // replace the example logic with your own plugin behavior
  registerCommand("hello", { description: "Says hello" }, async () => {
    return "Hello from my plugin";
  });

  registerAction("sum", async (_invoker, payload) => payload.a + payload.b);
};

export { onLoad };
```

`ctx.path` points to your plugin directory on disk. Use it when your plugin needs to read or write files relative to its own installation.

See [Components](./components) for the slot API and [Client SDK](./client-sdk) for the client runtime.

### 5) Build

Your plugin needs to be bundled before it can be used. There's a build script already set up for you, so you can just run:

```bash
bun run build
```

And your plugin will be bundled into the `dist` folder, which you can then install into your Sharkord instance (see [Installation](./installation) for more details).

Start with one command or one action first. Once the scaffold loads cleanly, add settings, UI, or voice features.
