title: Data

`ctx.data` is a small read-only window into the server's data. It is deliberately minimal, and it will grow.

| Method                       | Returns                             |
| ---------------------------- | ----------------------------------- |
| `getUser(userId)`            | `TJoinedPublicUser \| undefined`    |
| `getChannel(channelId)`      | `TChannel \| undefined`             |
| `getPublicUsers()`           | `TJoinedPublicUser[]`               |

All three are async. `getUser` and `getChannel` return `undefined` when the record does not exist, so check before using the result.

A public user carries `id`, `name`, `bio`, `profileColor`, `banned`, `createdAt`, and the avatar and banner files. Passwords, tokens, and identities are not exposed.

### Example

```ts
import type { PluginContext } from "@sharkord/plugin-sdk";

const onLoad = (ctx: PluginContext) => {
  ctx.events.on("user:joined", async ({ userId }) => {
    const user = await ctx.data.getUser(userId);

    if (!user) {
      ctx.logger.error("joined user not found", userId);
      return;
    }

    const users = await ctx.data.getPublicUsers();

    ctx.logger.debug(`${user.name} joined, ${users.length} users total`);
  });
};
```

### Limits

- Read-only. To change something, use [messages](./messages) or do it yourself against your own storage.
- No roles, permissions, or message history yet.
- Return types come from the server's internal types and are not stable across releases. Treat this API as experimental, like the rest of the SDK.
