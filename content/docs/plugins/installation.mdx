### Enable Plugins First

Plugins are off by default. Turn the plugin system on in the [server settings](/docs/administration/server-settings). Until you do, nothing is loaded and the marketplace is unavailable.

You need the `MANAGE_PLUGINS` permission to install and toggle plugins, and users need `USE_PLUGINS` to run their commands and actions.

### From the Marketplace

The marketplace is built into the interface. Browse it in the server settings, pick a plugin, and install. Sharkord downloads the release, verifies it against the checksum in the registry, and unpacks it into your data directory.

See [Marketplace](./marketplace) for what the listings mean and how to publish your own.

### Manually

1. Open your [data directory](/docs/data-dir).
2. Create a `plugins` folder if it does not exist.
3. Copy the built plugin folder (`dist/<plugin-id>` from the build) into it.
4. Open **Plugins** in the server settings. The folder is scanned live, so it shows up without a restart.
5. Enable it.

The result should look like this:

```
~/.config/sharkord/plugins/
  my-plugin/
    manifest.json
    server/index.js
    client/index.js
```

The folder name has to match the `id` in `manifest.json`, and all three files must be present, even for a plugin with no interface.

### Updating and Removing

Marketplace plugins can be updated and removed from the same screen. Sharkord unloads the plugin, replaces the files, and loads it again.

For manual installs, replace the folder's contents and toggle the plugin off and on.

### If It Does Not Load

Each plugin has a log view in the server settings, and load failures are recorded there with the reason. See [Troubleshooting](/docs/troubleshooting) for the common causes.
