<Alert type="attention" title="Security warning">
  Plugins run with full access to your server and to every user's browser. Read
  [Security](./security) first.
</Alert>

Plugins are off by default. Turn them on in the server settings first. Installing needs `MANAGE_PLUGINS`, using them needs `USE_PLUGINS`.

## From the Marketplace

Server settings → Plugins → Marketplace → install. The download is checked against the registry checksum. Updates and removal happen in the same place. See [Marketplace](./marketplace).

## Manually

Copy the built folder (`dist/<plugin-id>`) into `plugins/` in the [data directory](/docs/data-dir). It is picked up live, no restart. Enable it in the server settings.

```
~/.config/sharkord/plugins/
  my-plugin/
    manifest.json
    server/index.js
    client/index.js
```

The folder name must match the manifest `id`, and all three files must exist. To update, replace the contents and restart the server. Deleting the folder unloads it within seconds.

## Where Data Lives

| Location | Contents |
| --- | --- |
| `plugins/<plugin-id>/` | The plugin. Replaced on every update. |
| `plugin-data/<plugin-id>/` | Files the plugin wrote. Survives updates. |
| Database | Settings, per-user data, permission rules, installed version. |

Removing a plugin deletes all three. Files it attached to messages stay until those messages are deleted.

## Failed Loads

The plugin's **Logs** tab has the reason. Common causes are in [Troubleshooting](/docs/troubleshooting).
