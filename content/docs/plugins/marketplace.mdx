The marketplace is a registry of plugins, browsable from inside Sharkord. It is a public repository: [github.com/Sharkord/plugins](https://github.com/Sharkord/plugins).

### For Users

Open the server settings, browse the marketplace, and install with one click. Sharkord downloads the release from the URL in the registry and checks it against the published checksum before unpacking it.

<Alert type="attention" title="A listing is not a review">
  Anyone can publish. The `verified` badge means the maintainers recognise the
  publisher, not that the code was audited. See [Security](./security).
</Alert>

### For Developers

Publishing is a pull request against the registry repository. The plugin scaffold has a GitHub Actions workflow that does it all: it builds the plugin, creates a GitHub release, and opens the PR with the version file (checksum and download URL included).

The registry holds a `plugin.json` per plugin (id, name, description, author, logo, optional homepage, tags, categories, screenshots) and a `versions/<version>.json` per release (`version`, HTTPS `downloadUrl`, `checksum`, `sdkVersion`, `size`, `timestamp`). On a first publish the workflow generates `plugin.json` from your `manifest.json`, so fill in `screenshots`, `tags` and `categories` there first.

#### One-Time Setup

Create a [personal access token](https://github.com/settings/tokens) (classic, `public_repo` scope) on the account that should author the PR, and add it to your plugin's repository as an Actions secret named `MARKETPLACE_TOKEN`. The built-in token cannot open pull requests on other repositories.

#### Publish

1. Bump `version` in `package.json` and push.
2. In your repository, open **Actions → publish → Run workflow**.

That is all. Once the PR is merged, your plugin shows up in every server's marketplace.

This assumes a public GitHub repository. Hosting the release elsewhere means assembling the version file by hand.

<Alert type="info" title="sdkVersion pins compatibility">
  Servers only offer a version whose `sdkVersion` matches their own, so publish
  a new release after every SDK bump or existing installs cannot update.
</Alert>
