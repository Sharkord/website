A plugin is a folder of JavaScript that Sharkord loads into the server and, optionally, into every user's browser. Plugins add commands, buttons and whole screens, react to events, expose HTTP endpoints, and push audio and video into voice channels.

<Alert type="attention" title="Experimental">
  The plugin SDK is version 1 and still moving. Expect breaking changes between
  releases; a plugin's `sdkVersion` must match the server exactly or it will not
  load.
</Alert>

<Alert type="attention" title="Security warning">
  A plugin runs with the full privileges of the server process and of every
  user's browser session. Read [Security](./security) before installing
  anything.
</Alert>

### Shape of a Plugin

Every plugin is a folder inside `plugins/` in the [data directory](/docs/data-dir), containing:

```
my-plugin/
  manifest.json    # id, name, version, sdkVersion
  server/index.js  # runs in the server process
  client/index.js  # runs in every user's browser
```

All three are required, even when a plugin has no interface. The folder name must match the `id` in the manifest.

`server/index.js` must export two functions:

```ts
const onLoad = async (ctx: PluginContext) => {
  // register everything here
};

const onUnload = async (ctx: UnloadPluginContext) => {
  // stop timers, close connections, remove streams
};

export { onLoad, onUnload };
```

`onLoad` runs at server start and when the plugin is enabled. `onUnload` runs when it is disabled, removed, or updated. Commands, actions, events, settings, hooks, and HTTP routes are unregistered for you; anything you started yourself is not.

### What the Context Gives You

| API           | Use it for                                            |
| ------------- | ----------------------------------------------------- |
| [Commands](./commands)   | Slash commands users can run                |
| [Actions](./actions)     | Server functions your UI can call           |
| [Components](./components) | React components in fixed slots of the app |
| [Events](./events)       | Reacting to messages, joins, and voice      |
| [Settings](./settings)   | Typed options an admin edits in the UI      |
| [Messages](./messages)   | Sending, editing, and deleting messages     |
| [Data](./data)           | Reading users and channels                  |
| [Hooks](./hooks)         | Intercepting file saves                     |
| [HTTP](./http)           | Your own HTTP endpoints                     |
| [Voice](./voice)         | Publishing external audio and video streams |

The [Client SDK](./client-sdk) covers the browser half, and [API Reference](./api-reference) lists the whole surface in one place.
