Press **F9** in a voice channel for connection diagnostics. Set `debug=true` in [`config.ini`](/docs/configuration) for verbose server logs.

<Accordion>
  <AccordionItem title="Voice, webcam or screen sharing does not work">
    - You are on HTTPS or `http://localhost`. See [Why HTTPS](/docs/https/why).
    - Port `40000` is open on **both UDP and TCP**, in the firewall and the router.
    - Behind NAT, Docker or a cloud provider, `webRtc.announcedAddress` is set to the public IP or domain, and that domain is not behind a CDN proxy.
  </AccordionItem>
  <AccordionItem title="Everyone gets 'Too many requests'">
    Users are being counted as your proxy's IP. The server logs the address to trust. Usually a CDN like Cloudflare in front of your proxy. See [Behind a Proxy](/docs/https/behind-a-proxy).
  </AccordionItem>
  <AccordionItem title="Uploads fail">
    Failing instantly with `413`: your proxy caps body size. Nginx needs `client_max_body_size 0`. Error about size or quota: Sharkord's own [storage limits](/docs/administration/storage).
  </AccordionItem>
  <AccordionItem title="Disconnects with code 1006">
    The WebSocket was cut, almost always by a proxy read timeout or an idle timeout in the network. Known cases: [#46](https://github.com/Sharkord/sharkord/issues/46), [#289](https://github.com/Sharkord/sharkord/issues/289), [#259](https://github.com/Sharkord/sharkord/issues/259).
  </AccordionItem>
  <AccordionItem title="The server will not start">
    - **Windows:** install the [Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe).
    - **Port in use:** change `server.port` or stop the other process.
    - **Permissions:** the data directory must be writable. In Docker, set `PUID` and `PGID`.
  </AccordionItem>
  <AccordionItem title="config.ini changes do nothing or revert">
    It is only read at startup. A file that fails validation is replaced by the defaults, with the reason in the log.
  </AccordionItem>
  <AccordionItem title="A plugin does not load">
    The reason is in the plugin's **Logs** tab. Usual causes:

    - Plugins are off in the server settings.
    - The folder name does not match the manifest `id`.
    - `manifest.json`, `server/index.js` or `client/index.js` is missing.
    - No `onLoad` export.
    - `sdkVersion` does not match the server.
    - `onLoad` or `onUpgrade` threw or took over 30 seconds.
  </AccordionItem>
</Accordion>

Still stuck? Search the [issues](https://github.com/Sharkord/sharkord/issues) or ask in [discussions](https://github.com/Sharkord/sharkord/discussions).
