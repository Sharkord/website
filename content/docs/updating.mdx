<Alert type="warning" title="Back up first">
  Copy the [data directory](/docs/data-dir) before every update. Migrations
  only go forward.
</Alert>

**Binary:** stop the server, replace the binary with the [latest release](https://github.com/Sharkord/sharkord/releases/latest), start it. Pending [migrations](/docs/migrations) run on start.

**Docker Compose:**

```bash
docker compose pull
docker compose up -d
```

**Docker:** `docker pull`, remove the container, run it again with the same command.

Check the running version:

```bash
curl -sI https://your-server/healthz | grep -i x-sharkord-version
```

## Self Update

Not available in Docker or dev builds.

- **Update button** in the server settings, needs **Manage updates**.
- **`autoupdate=true`** in [`config.ini`](/docs/configuration) checks GitHub at startup and every hour.

<Alert type="attention" title="Unreliable for now">
  A failed self update can leave the server down until you replace the binary
  by hand. Prefer updating manually.
</Alert>
